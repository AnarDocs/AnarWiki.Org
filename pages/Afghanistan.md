**Afghanistan** is a
<a href="State_(polity)" class="wikilink" title="state">state</a>
located in
<a href="South_Asia" class="wikilink" title="South Asia">South Asia</a>
(although some call it
<a href="West" class="wikilink" title="West">West</a> or
<a href="Central_Asia" class="wikilink" title="Central Asia">Central
Asia</a>). It is currently under the control of an authoritarian
<a href="Islam" class="wikilink" title="Islamic">Islamic</a> theocracy
(officially the "Islamic Emirate of Afghanistan") and borders the other
states of <a href="China" class="wikilink" title="China">China</a>,
<a href="Iran" class="wikilink" title="Iran">Iran</a>,
<a href="Pakistan" class="wikilink" title="Pakistan">Pakistan</a>,
<a href="Tajikistan" class="wikilink" title="Tajikistan">Tajikistan</a>,
<a href="Turkmenistan" class="wikilink"
title="Turkmenistan">Turkmenistan</a> and
<a href="Uzbekistan" class="wikilink" title="Uzbekistan">Uzbekistan</a>.
